# Shekhar_Python

A collection of Python scripts and practice projects.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shekhar1August/Shekhar_Python.git
   cd Shekhar_Python
   ```
2. Make sure Python 3 is installed:
   ```bash
   python3 --version
   ```
3. Run a script:
   ```bash
   python3 <script_name>.py
   ```
